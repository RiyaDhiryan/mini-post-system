# 📝 PostSphere - MERN Post Management System

A full-stack MERN application that enables users to register, log in, and manage their posts efficiently. The application provides complete CRUD functionality with a responsive user interface built using React and Tailwind CSS, while MongoDB handles persistent data storage.

## 🚀 Features

* 🔐 User Registration & Login
* 👤 User Profile Management
* ➕ Create New Posts
* ✏️ Edit Existing Posts
* 🗑️ Delete Posts
* ⚡ Real-Time Updates
* 📱 Fully Responsive Design
* 🎨 Modern UI with Tailwind CSS
* 🌐 REST API Integration
* 📂 User-Specific Post Management

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/RiyaDhiryan/mini-post-system.git
```

### Backend Setup

```bash
cd Backend
npm install
npm start
```

### Frontend Setup

```bash
cd Frontend
npm install
npm run dev
```
